# assets-source

Originals only. Nothing here ships — Phase 2+ derives cropped, resized and
format-converted files from these and puts them in `public/` or Supabase Storage.

- `brand/blob-mark.png` — the mark, as supplied. In the app it is an inline
  `currentColor` SVG so it can be tinted and scaled from 32px to 30rem from one path.
- `brand/wordmark.png` — `basıc` (dotless ı), cream on black, extracted from the deck.
- `deck/` — 26 photographs extracted from `desserts_presentation_sr.pptx`, original
  filenames preserved so they match the mapping table in `docs/content-source.md` §5.

Two 17×17px spacer artifacts from the deck were discarded.
